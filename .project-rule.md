# ZView Directives

- High-performance, lightweight, and modern image viewer adhering to ZeroUniverse Architecture v4.0.
- Decouple image decoding, folder navigation, and memory caching into `ZView.Core`.
- Integrate `ZeroUI.Wpf.Media` (`ZImageViewer`, `ZPictureEdit`, `ZThumbnailGrid`, etc.) for GPU-accelerated rendering and forensic inspection.
- Employ multi-tiered decoding (WIC Hardware acceleration + ImageSharp/fallback for modern formats).
- Utilize LRU memory caching with background pre-fetching engine for zero-latency next/previous image navigation.
- Implement non-blocking asynchronous file loading and zero-lock file access streams.
- Follow WPF Desktop UI & Theming Standards (`E:\16. AgentOption\standards\csharp\wpf-ui.md`).
